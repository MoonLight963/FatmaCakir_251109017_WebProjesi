# Web Programlama Projesi - Model Konser Bilet Sistemi

Hocam merhabalar, ben Fatma Çakır (Öğrenci No: 251109017). 

Bu projede efsane Model grubuna olan sevgimi web programlamayla birleştirmek istedim. Sitede Model'in şarkılarını dinleyip yaklaşan konserlerine bilet alabileceğimiz bir sistem kurdum.

##  Projede Neler Yaptım?
* **Tasarım:** Sitenin HTML ve CSS kısımlarını baştan sona kendim tasarladım. Kodları incelerken göreceksiniz, CSS class'larını kendi ismimin baş harfiyle `f-` isimlendirdim.
* **Veritabanı Mantığı:** Sistemde `kullanicilar`, `konserler` ve `biletler` olmak üzere 3 tablom var. Bilet alma aşamasında bu tabloları birbiriyle ilişkili hale getirdim.
* **Oturum İşlemleri:** Siteye kayıt olma ve giriş yapma kısımlarını hallettim. Giriş yapmayan ziyaretçilere bilet aldırmıyorum, login sayfasına yönlendiriyorum. 
* **Dinamik Menü:** Ziyaretçi giriş yaptığında menüdeki Giriş Yap yazısı kayboluyor, yerine Admin Paneli ve Çıkış Yap geliyor. 
* **Admin Paneli (CRUD):** Giriş yapınca erişilebilen bu panelden veritabanına yeni konser ekleyebiliyor (POST), mevcut konserleri çekip listeleyebiliyor (GET) ve konser silebiliyoruz (DELETE).
